What to look for

  • The first chunk is level 0 — the whole image at 32×16 — so first paint is 263 bytes, 0.018% of the stream.
  • Each level replaces its parent everywhere at once, so the picture sharpens as a whole rather than filling in as tiles.
  • Drag a rectangle in ROI mode: the same file is re-requested with the selected region's byte spans first. Full detail inside the region costs about 22% of the stream, held up by the coarse pyramid underneath it.
  • The bandwidth slider shapes the stream client-side, which is the honest way to show refinement order at 56k-ish speeds.
